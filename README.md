# Crop Yield Prediction

Exploratory analysis and modeling for crop yield (hg/ha) across countries and crops.  
Contains EDA, geospatial visualisations, feature engineering and a model comparison pipeline including Linear Regression, Random Forest, Gradient Boosting and XGBoost.

## Files
- `crop-yield-prediction.ipynb` — main notebook (EDA, visualisations, model training & evaluation)  
- `requirements.txt` — Python dependencies  
- `.gitignore` — ignored files  
- `assets/` — optional: save plots, maps, model output

## Notes
- Uses geopandas and plotly for maps and interactive plots.  
- Uses several regressors and cross-validation to compare model performance.
